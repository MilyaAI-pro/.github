
# Milya AI Engineering

This repository contains shared engineering templates and contribution guidelines for the Milya AI GitHub organization.

## Shared Templates

- Bug Report
- Feature Request
- Pull Request

## Projects

- Milya Scribe
- Milya Receptionist

## Engineering Guidelines

All development work should follow:
1. Create an issue for new features or bugs.
2. Work on a dedicated feature or bug-fix branch.
3. Open a pull request for code changes.
4. Obtain code review before merging.
5. Update relevant documentation.
